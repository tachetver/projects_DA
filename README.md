## Учебные проекты по аналитике данных

### Сборный проект-1
Папка: `part-project-1`  
Описание: исследование закономерностей успешности компьютерных игр на основе исторических данных для прогнозирования популярности новых релизов и планирования рекламных кампаний.

### Сборный проект-2
Папка: `part-project-2`  
Описание: анализ воронки продаж и результатов A/A/B-теста мобильного приложения для оптимизации пользовательского опыта и повышения продаж.

### Анализ убытков приложения
Папка: `app`  
Описание: анализ причин убыточности приложения при высоких рекламных бюджетах и разработка рекомендаций по оптимизации маркетинговой стратегии.

### Исследование надежности заемщиков
Папка: `bank`  
Описание: анализ факторов платежеспособности клиентов банка для выявления закономерностей своевременного погашения займов и подготовки данных к построению модели кредитного скоринга.

### Сервис для чтения книг
Папка: `book-service`  
Описание: анализ базы данных сервиса чтения книг по подписке для формирования ценностного предложения нового продукта.

### Проверка гипотез для увеличения выручки в интернет-магазине 
Папка: `e-store`  
Описание: приоритизация гипотез роста, проведение A/B-теста и анализ результатов для увеличения выручки интернет-магазина.

### Рынок заведений общественного питания Москвы
Папка: `moscow-places`  
Описание: исследование рынка общественного питания Москвы для определения оптимального формата и локации нового заведения.

### Анализ данных Яндекс Музыки
Папка: `yandex-music`  
Описание: сравнение музыкальных предпочтений и паттернов активности пользователей Яндекс Музыки в Москве и Санкт-Петербурге.

### Исследование объявлений о продаже квартир
Папка: `yandex-real-estate`  
Описание: исследовательский анализ данных Яндекс.Недвижимости для выявления закономерностей ценообразования и аномалий на рынке квартир Санкт-Петербурга.

### Дашборд для Яндекс.Дзен
Папка: `yandex-zen`  
Описание: разработка дашборда для мониторинга пользовательского поведения на платформе Яндекс.Дзен
